# 自重练习

微信自重训练指导与打卡小程序，包含力量跟练、间歇有氧计时、动作库与训练日历。

## 功能

- 根据目标、经验、训练时长和器材生成力量计划。
- 记录每组次数、余力和动作稳定性，支持跳过、回退与补做。
- 双列动作卡片与两帧动作示意，配有关节标记和操作要点。
- 自选有氧运动，设置快段、恢复段、轮数、热身和放松。
- 有氧计时支持暂停、继续与提前结束，进入后台时暂停。
- 日历用绿色标记完成、黄色标记部分完成，有氧训练另带闪电标记。
- 历史记录支持删除，与日历和周统计同步。
- 液态玻璃界面，针对手机窄屏和底部安全区域调整布局。

## 本地运行

1. 下载或克隆仓库。
2. 在微信开发者工具中导入 `miniprogram` 目录。
3. 将项目中的 `touristappid` 替换为自己的小程序 AppID。真机预览和上传需要具备对应账号权限。
4. 点击编译，按需生成训练计划或开始间歇有氧。

项目使用原生 JavaScript、WXML 和 WXSS，无需安装前端依赖。请保留个人 AppID 和开发者工具私有配置在本地。

## 数据保存

训练设置、当前进度和历史记录保存在当前设备微信的本地缓存中。当前版本提供本地保存，云端备份与跨设备同步有待开发。

## 目录

```text
miniprogram/
  app.js / app.json / app.wxss
  pages/index/       页面与交互
  utils/            力量训练、有氧计时与动作标签
  assets/           动作 SVG 与界面图标
```
