# 自重练习 · 微信小程序本地体验版

1. 解压工程包，在微信开发者工具中导入包含 `project.config.json` 的文件夹。
2. 选择小程序项目。有自己的 AppID 时可填入；没有 AppID 时可先使用开发者工具提供的本地测试模式。工具界面如要求重新选择 AppID，以当前版本提供的选项为准。
3. 编译后进入「今天」，选「零基础、15 分钟、弹力带」生成计划。完成一组、跳过再返回补做、查看小结，然后去「我的」查看日历。
4. 真机预览、体验版发布、登录和多设备同步需要另行配置。

首版数据保存在当前小程序环境中。网页原型和小程序使用各自的存储，已有网页训练记录不会自动导入。月历绿色代表至少一条完整训练，浅黄色代表只有部分完成，空白代表没有记录训练组。删除单条记录会同步更新月历和本周统计。

动作示意沿用原型的教练形象和 SVG 关节标记。工具导入后建议先检查动作图、休息计时和小屏幕下的跟练布局。
